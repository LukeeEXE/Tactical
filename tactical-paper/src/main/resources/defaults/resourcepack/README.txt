Tactical resource pack sources
==============================
Put your art here, then run /game pack rebuild in-game (no restart needed).

assets/tactical/textures/block/<name>.png   textures for custom blocks (see ../blocks/*.yml)
assets/tactical/models/block/<name>.json    optional Blockbench models for custom blocks
assets/minecraft/...                        vanilla overrides using normal pack paths, e.g.
                                            assets/minecraft/textures/block/stone.png
                                            (changes that block EVERYWHERE on the server)
overrides/...                               copied into the pack verbatim (highest priority),
                                            e.g. overrides/assets/minecraft/sounds.json

Rules: PNG, square (16x16 to 128x128 typical); animated textures need a .png.mcmeta next to them.
The hunger-variant food sprites are generated by the plugin (they hide the hunger bar) and cannot be replaced.
Files in this folder are never overwritten by plugin updates.
